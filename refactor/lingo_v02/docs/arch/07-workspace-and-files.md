# 07 — Workspace and Files

## Workspace layout

```text
my-hindi-library/
  library.db          # SOURCE OF TRUTH
  config.toml         # typed library settings
  AGENTS.md           # agent handoff rules generated by init

  raw/                # user-owned source input
    chapter01.md

  runs/               # in-flight prompt/reply handoff
    ch01-enrich-9b2c/
      task.md
      reply.json
      run.json

  audio/              # derived internal audio, flat by sentence id
    sen-01jx9m7q8v6f2x4k9d3p1r0t5w.mp3
    sen-01jx9m7q8v6f2x4k9d3p1r0t5x.mp3

  out/                # derived publish artifacts
    ch01/
    study/
    ch01.apkg

  prompts/            # optional user overrides for prompt templates
```

## File categories

| Category | Paths | Rule |
|---|---|---|
| Truth | `library.db` | Canonical. |
| Config truth | `config.toml` | Parsed into typed config. |
| User input | `raw/`, `prompts/` | Lingo reads; user owns content. |
| In-flight | `runs/` | Pending work; do not delete until applied/abandoned intentionally. |
| Derived | `audio/`, `out/` | Regenerable from DB/config/input. |
| Mirror | `runs/*/run.json` | Portable mirror; DB run row wins. |

## Typed path model

```rust
pub struct WorkspaceRoot(PathBuf);
pub struct WorkspaceRelativePath(String);
pub struct RunRelativePath(WorkspaceRelativePath);
pub struct AudioRelativePath(WorkspaceRelativePath);
pub struct OutputRelativePath(WorkspaceRelativePath);
pub struct ResolvedWorkspacePath(PathBuf);
```

Use shared mechanics for safe relative path parsing, but keep domain wrappers distinct.

```rust
impl WorkspaceRelativePath {
    pub fn parse(raw: impl Into<String>) -> Result<Self, RelativePathError> {
        let raw = raw.into();
        reject_empty(&raw)?;
        reject_absolute(&raw)?;
        reject_parent_segments(&raw)?;
        reject_backslashes(&raw)?;
        Ok(Self(raw))
    }
}
```

## Prompt template lookup

Built-in templates live in crate source and are versioned with the binary. In the
first refactor pass they live under `lingo-service`; split them to
`lingo-handoff` only when the boundary earns its own crate.

```text
crates/lingo-service/templates/
  extract.md.hbs
  enrich.md.hbs
  qa.md.hbs
```

Workspace overrides are optional:

```text
prompts/
  extract.md.hbs
  enrich.md.hbs
  qa.md.hbs
```

`HandoffPort::render_task` must check `prompts/` first and fall back to built-in
templates. Missing workspace overrides are normal. Invalid workspace templates
should fail with a clear path in the error and should not silently fall back,
because that would hide user edits.

## Audio path policy

```rust
pub struct AudioPathPolicy;

impl AudioPathPolicy {
    pub fn relative_path(sentence: &SentenceId) -> AudioRelativePath {
        AudioRelativePath::parse(format!("audio/{}.mp3", sentence.as_str()))
            .expect("sentence ids produce safe audio paths")
    }
}
```

A deck slug rename does not move audio files.

## Run manifest

`run.json` is a portable mirror:

```json
{
  "run": "ch01-enrich-9b2c",
  "stage": "enrich",
  "deck": "ch01",
  "status": "pending",
  "task": "task.md",
  "reply": "reply.json",
  "created": "2026-06-29T10:32:00Z"
}
```

If DB and manifest disagree:

```text
DB wins.
Workspace adapter repairs run.json from DB before continuing.
```

## Config shape

```toml
[target]
profile = "hindi"

[library]
title = "Lingo Sentences"
language = "hi"

[display]
lead = "romanisation"
show_secondary = true
ascii = false

[audio]
backend = "gtts"

[publish]
package = "out/<deck>"
study = "out/study"
anki = "out/<deck>.apkg"
deck = "Lingo::Sentences"
```

Config keys are a closed vocabulary:

```rust
pub enum ConfigKey {
    TargetProfile,
    LibraryTitle,
    LibraryLanguage,
    DisplayLead,
    DisplayShowSecondary,
    DisplayAscii,
    AudioBackend,
    PublishPackage,
    PublishStudy,
    PublishAnki,
    PublishDeck,
}

impl ConfigKey {
    pub const fn dotted(self) -> &'static str {
        match self {
            Self::TargetProfile => "target.profile",
            Self::LibraryTitle => "library.title",
            Self::LibraryLanguage => "library.language",
            Self::DisplayLead => "display.lead",
            Self::DisplayShowSecondary => "display.show_secondary",
            Self::DisplayAscii => "display.ascii",
            Self::AudioBackend => "audio.backend",
            Self::PublishPackage => "publish.package",
            Self::PublishStudy => "publish.study",
            Self::PublishAnki => "publish.anki",
            Self::PublishDeck => "publish.deck",
        }
    }
}
```

## `init --example`

`init --example` writes a concrete raw file so `Next:` is copyable.

```text
raw/example.md
```

Without `--example`, the service returns `Blocked(NeedsRawFile)` and the CLI prints instructions, not a placeholder `Next:`.

## Atomic file writes

```rust
pub fn atomic_write_verified(path: &Path, bytes: &[u8]) -> Result<(), AtomicWriteError> {
    let tmp = temp_sibling(path);
    std::fs::write(&tmp, bytes)?;
    std::fs::rename(&tmp, path)?;
    let read_back = std::fs::read(path)?;
    if read_back != bytes {
        return Err(AtomicWriteError::VerificationFailed);
    }
    Ok(())
}
```

Use for:

- `task.md`;
- `run.json`;
- `config.toml`;
- audio files;
- package manifests;
- study SQLite final rename.
