# 12 — Testing and Evidence

## Testing strategy

Use tracer-bullet evidence first, then harden with focused invariants.

The first vertical slice should prove:

```text
init --example
prepare extract run
write reply.yaml
apply --dry-run
apply commit
status shows drafts
prepare enrich run
visible status derives enriching from run_sentences
apply enrich
approve one sentence
study/anki snapshot selects approved rows only
```

Do not build a huge matrix before the first slice validates the API and schema shape.

## Study export fixture

Create and maintain this fixture before Grasp integration starts:

```text
fixtures/study-export/
  study.sqlite
  manifest.json
  audio/
    ch01/sen-....mp3
```

The fixture should contain two decks, three sentences, a populated `words` table,
`word_sentences`, tags, and relative audio paths. Grasp should code against this
fixture, not against a moving implementation detail. `publish --format study` on
the same source data must produce a schema-compatible output.

## Architecture evidence

- Cargo dependency audit for forbidden arrows.
- Grep/codemap check that `lingo-domain` has no `rusqlite`, `clap`, filesystem layout, or CLI renderer imports.
- Grep/codemap check that command modules do not contain SQL strings.
- Tests proving fake repository implements service port.
- No broad `utils`, `common`, or magic string vocabulary crates.

## Acceptance checklist

```text
[ ] schema initializes from schema_v02.sql
[ ] all DB connections set WAL + foreign_keys
[ ] meta.library_id exists and is package-exported
[ ] status derives enriching from pending run_sentences
[ ] active=true draft row is impossible in domain and DB
[ ] semantic target edit downgrades to draft and clears approval
[ ] audio-only target edit keeps lifecycle/QA/tokens/approval and marks audio stale by fingerprint
[ ] generated/imported/manual origin round-trips
[ ] run cleanup does not erase sentence origin
[ ] apply --dry-run validates and writes nothing
[ ] apply commit is one transaction
[ ] apply retry leaves failed run pending
[ ] same-hash reapply is idempotent
[ ] different-hash reapply errors
[ ] one-pending-enrich-claim concurrency test rejects double claim
[ ] target semantic edit invalidates AI derived fields only
[ ] audio paths are flat by sentence id
[ ] deck slug rename does not move audio
[ ] word keys use language profile
[ ] audio fingerprints use profile/backend/voice/model/lang/text
[ ] study/anki default to active approved enriched rows
[ ] package export/import round-trips approval, QA, authority, tokens, origin
[ ] cross-library import resets approval/QA by default
[ ] MySQL appendix is not wired into implementation
```
